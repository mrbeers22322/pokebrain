# Recommended MVP Tech Stack

## Recommendation

Start with:

- Python
- SQLite
- FastAPI
- Jinja/HTMX or simple server-rendered pages

## Why

This keeps the MVP simple:

- One local database file
- Easy backups
- Easy imports
- No cloud complexity
- No authentication complexity at first
- Easy migration later

## Later Upgrade Path

If the project grows:

- PostgreSQL for production
- React or Vue frontend
- User accounts
- Hosted API
- Billing/subscriptions
- Multi-user trade matching
