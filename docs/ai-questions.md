# AI Questions System

The AI Questions page is a two-way communication system.

## AI asks the user

AI should ask when missing data affects a decision.

Examples:
- Is this Pokémon shiny?
- Does this Pokémon have a special background?
- Is this Pokémon Dynamax?
- Is this your only copy?
- Is this safe for mirror trade?
- What kind of player are you?

## User asks AI

Examples:
- Should I evolve this?
- Should I transfer this?
- What should I walk?
- What team should I use?
- What should I mirror trade?
- What should I build next?

## Rule

Do not ask questions for trivia. Ask questions that change recommendations.
