# PokeBrain Vision

## One Sentence

PokeBrain is an AI-powered Pokémon GO command center that helps trainers understand their account, prioritize actions, build teams, plan trades, track projects, and ask AI what to do next.

## Core Principles

1. One Pokémon = one clean database record.
2. Every field should know where it came from.
3. AI should explain recommendations.
4. AI should ask questions when confidence is low.
5. Recommendations should be personalized to player style.
6. Everything should be auditable later.
7. The system should support future team building.
8. The system should support future multi-user trade matching.
9. User feedback should help prioritize product updates.
10. The MVP should be simple enough to actually build.
